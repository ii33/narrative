# 工程图存储（schema 10）

当前模型以 [数据模型](DATA_MODEL.md) 为准。

- `objects` 按 ID 保存当前节点、语境、时间轴与原文顺序；不保存节点旧副本。
- `property_records` 只保存当前属性定义与实际取值区间。每个值自带 `valid_from` / `valid_to`，没有属性撤回记录或长期别名链。
- `sources` 保存不可变原文；Library 附件、原始模型输出和任务诊断独立保留。
- `revision` 只作并发 token。轻量 `actions` 保存动作、原因及变更 ID / 数量，不保存整份前后对象。

正常状态更新结束旧区间并追加新值；录入错误直接更正或删除。事件合并和属性改名、合并物理重写类型化引用，不改恰好等于 ID 的字符串正文。

所有活动事件必须属于活动场景；活动物品必须有当前 world 持有者节点或显式“无”“未知”。写入经 Operations 的完整拟写状态静态验证，不依赖人工审批。

回退按原文来源顺序及 Unicode 位置删除后续事实，清理引用并开放被截断的旧区间。无披露坐标的手工节点无法归时，预览明确说明并保留，不猜测删除。原文与附件不随回退删除。

仅支持当前 schema 10。旧版工程拒绝打开，不提供兼容读写、转换或迁移入口。
