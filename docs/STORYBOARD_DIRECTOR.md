# 分镜导演台设计与分期实施方案

左侧提供“分镜稿”和“导演台”两个独立模块。分镜稿负责按场读写镜头文稿、画格与图文导出；导演台负责镜头时间轨、场面调度、机位和动态预演。二者共用同一份本场分镜数据与修订，切换时保留当前场次和镜头，隐藏模块暂停播放，不创建另一套业务数据。分场剧本的“进入分镜”先打开分镜稿。

导演从分场剧本直接排镜，再进入导演台在同一条时间轴上看素描、调走位、听节奏。先定镜头方案，再定项目风格，最后逐镜生成并放回全场验片。单镜可引用多个正文块，同一正文块可由多个镜头表现。制作稿和独立的元素提取步骤退出主流程。

**实现状态。** 已有按场排镜、正文引用、静帧保持与切换、逐帧／循环、二维调度、命名时刻、临时声轨、机位轨与2.5D运镜预演。素描与风格帧通过实际图像服务生成，几何轮廓仅作内部输入。第三期提供局部图层／平面机位动画、风格对照、干净MP4导出，以及视频服务的准备、提交、查询回填和明确选段采用。2.5D仍是无网格近似，不代替白模；真实视频服务验收依赖相应凭据，不能以本地媒体回放或协议测试冒充。具体合同见[时间与二维调度](STORYBOARD_TIMING.md)、[图像生成](STORYBOARD_STYLE_PROVIDER.md)和[视频生成与采用](STORYBOARD_VIDEO.md)。下文保留完整实施目标与分期验收标准。

## 分镜稿先行

进入一场先读分镜稿。镜号按当前顺序显示，标题和镜头正文分开。正文讲清观看位置、画面变化、动作及揭露时机；镜头语言和时长可随后填写。画面说明在没有图时也能独立阅读。分镜稿模块内提供文稿与图格画板；导演台提供编排和预演，两模块共享本场镜头身份。进入导演台后在对应镜头看片，返回时仍可找到同一镜。

视觉元素在本镜直接填写，例如头盔、玻璃及其可见状态，可以绑定项目资源。人物动作和机位调度按需要补充。声音意图由场共享，多个镜头可以引用同一句对白或同一段录音；镜头各自说明本镜怎样听见它，实际音频和起止时间到编排阶段落实。

一个镜头可以有多个画格计划。先写画格意图，随后选择底图、绑定已有帧或生成候选；同一画格的不同候选共享该格身份，不增加镜数。新镜起头与本镜添格是两种操作。静止等待可以延长已有画面。画格底图和导演标注分层，标注坐标相对画布归一化。

导出本场可选 TXT、HTML 或 PDF，后两者可带图和标注。图文 PDF 的文字稿按阅读顺序排列，后附固定六格版式的画格图版；尚无画面的格子仍占槽位。HTML 把图片嵌入文件，可以脱离工程传阅。每次导出注明分镜修订，写到新文件，保留已分享的稿次。动态分镜 MP4 继续从编排导出。

## 一场戏怎样定案

| 阶段 | 导演的操作 | 进入下一阶段前看什么 |
|---|---|---|
| 分镜与调度 | 在横轨上铺开镜头，确定观看重点、机位和预计时长。普通镜头可直接构图，多机位共用的动作在场调度板上安排 | 切镜前后人物在哪，视线朝哪，观众何时获得新信息 |
| 素描关键帧 | 根据本镜正文、机位视图、调度和项目公共资产，为决定性时刻生成、导入或修改描述型素描，可选简彩 | 姿态、手与道具的接触、遮挡、主要形体的受光与背光，以及必要投影是否清楚 |
| 草图动画 | 默认按时保持和直接切换静帧。需要连续运动的区间才启用图层或摄影机动画。按需加入临时对白、效果声与静默 | 全场联播检查运动方向、揭露、停顿与切点，满意后按场定案 |
| 风格化关键帧 | 选定已认可的时刻，结合角色、服装、场景、道具参考和项目风格转绘。允许并排或叠看草图与结果 | 保住构图、姿态和显露顺序，确认角色外观、材质与色彩 |
| 正式生成 | 按镜导出干净的草图动画、风格参考帧及必要文字，选择生成方式。将返回的视频选段放回原镜头 | 先验动作与画面，再联播验节奏。记录采用的素材及入出点 |

**素描标准。** 以《AI影视分镜素描风格与制作指南》的描述型示例为目标。读信时，低头方向、手指压住纸边、窗光落在哪一侧，都比衣料纹理优先。冷暖、信号色或烟障颜色影响观众判断时可在简彩版中保留。用于区分人物的编辑色、编号和运动箭头只出现在导演视图中。

## 工作区与播放

上方并排显示画面预览和场面调度板，可单独放大。下方是一条横向镜头轨，镜头宽度反映时长；展开一镜后可见素描缩略图、摄影机、指定对象、声音和命名时刻。侧栏随选择显示正文、资源或调度属性。进入本场即可用单张静帧排镜，调度板按需要打开。

播放、暂停、拖动、逐帧和选段循环共用一个播放头。点正文可定位关联镜头，点时间标记可定位两侧视图；拖素描帧调整换图时间，拖场上对象在当前动作时刻修改站位。开启记录关键点时，编辑前显示目标对象和时间。移动共享动作节点前预览受影响镜头。

| 内容 | 给定播放时刻的画法 |
|---|---|
| 画面预览 | 显示本镜中最近一个已经到达的关键帧，保持到下一帧。首帧之前显示待补画面。单镜一张起始图即可贯穿全镜 |
| 调度板 | 从动作轨求人物、道具的位置和朝向，同时显示当前机位及视野。画面保持静止期间，调度板仍可连续运动 |
| 切点 | 立即切换到下一镜及其机位。人物状态取下一镜所引用的场内动作时刻；连续动作自然接上，反打或重看可显式回到较早时刻 |
| 审阅版本 | 同一时间点切换草图、风格帧和已采用视频。素材缺失时标明缺失或回退来源，避免误判交付状态 |

## 时间与数据约定

分开保存三个时间量。**场剪辑时间**是播放头位置，镜头顺序和时长决定各镜在成片中的区间。**镜内时间**从镜头起点算起，素描帧、机位轨和本镜声音使用该坐标。**场内动作时间**表示人物与道具的共同表演，可被不同机位重复取用。首期把一个镜头连续映射到一段等速动作，可指定起点。例：第二镜从场剪辑第 3 秒开始，却可从动作第 2.5 秒切入，重看半秒敲击；两个机位读的是同一次敲击。

程序统一存毫秒，逐帧浏览按预演帧率换算。镜头区间采用左闭右开，恰在切点取下一镜，总片尾停在最后一镜末画面。调序只改变剪辑位置。缩短镜头会挤出关键帧或命名时刻时，先显示冲突，显式移动或删除后一次保存。

| 对象 | 归属和最少记录 |
|---|---|
| 场调度与场面对象 | 本场空间坐标、人物／道具／布景、资源引用、可选父对象与深度层。世界方向和画面左右分别表达 |
| 动作轨与命名时刻 | 对象、动作时间、位置、朝向或状态、保持／线性过渡；“指节碰到玻璃”等可引用的时刻 |
| 镜头 | 场、正文块引用、顺序、时长、动作时间映射、描述、观看重点、摄影机轨与运镜预设 |
| 摄影机关键点 | 镜内时间、机位、朝向、视野或焦距、跟随／注视目标、构图约束和速度曲线 |
| 素描关键帧 | 镜内时间或关联标记、草图、风格图、资产依据与必须保留的关系。独立选择保持、切换或适用的动画区间 |
| 生成与审阅 | 输入素材及依据、目标时长、返回文件、采用区间、待复核原因。公共资源按项目复用，本镜文件关联具体镜头或帧 |

模型和界面使用稳定可读编号，例如 shot-3、frame-2、camera-1。排序和改名保留身份。界面、CLI 和模型都通过 Operations 编辑；程序校验同场引用、时间范围和修订，内部生成文件摘要。正式材料和原始附件保留各自引用。

## 调度精度、运镜与模型输入

**二维调度先行。** 导演可摆人物、道具、机位与遮挡物，画路径、转身、停顿和视锥。2.5D 再加入前中后景深度，从机位导出构图底图。若绕拍需要看见物体侧面，或窗框遮挡关系难以判断，再给该镜使用白模。二维布局尚不足以推算的细节由导演补画或明确指定。

**运镜预设保存运动关系。** 基础预设包含固定、推拉、横移、升降、摇摄和光学变焦；相对主体预设包含跟随、环绕和揭示；复合预设可联动机位与焦距。例如希区柯克变焦让导演选择主体、锁定主体画面占比、指定推进方向与时长，由程序联动焦距并按场景深度预演。速度曲线、轻微手持和移焦可单独叠加。每个预设可展开编辑，并保存为项目预设。

| 模型任务 | 实际交付的输入 |
|---|---|
| 规划分镜 | 本场正文、创作约定、共享场面俯视图与格式化的走位说明 |
| 绘制某张素描 | 此时刻的机位视图、关键姿态、可见／隐藏关系、主光和相关资产 |
| 生成草图动画 | 定时素描、人物和摄影机轨迹、命名时刻、须保持和须变化的内容。可确定计算的图层运动直接渲染 |
| 风格化 | 已定案的单帧草图、外观参考、项目风格与必须保留项 |
| 正式视频 | 单镜无标注预演、风格参考帧、动作因果和时间说明。允许在提交前查看实际图片、视频和提示词 |

生成适配器区分“参考运动＋外观”和“指定首尾帧”两种意图，按供应商实际能力组装输入。以 H3 为例，参考视频和参考图片可以同用，参考模式与指定首尾帧模式互斥。导演台内的时间与关键帧持续可编辑，供应商的时长限制在提交时显式处理。[MiniMax H3 接口](https://platform.minimax.io/docs/api-reference/video-generation-v2-create)

## 分期与验收

| 顺序 | 交付范围 | 可复现的验收 |
|---|---|---|
| 一 | 强化现有静帧轨，支持拖关键帧、逐帧与循环；二维调度板接共用播放头，支持保持和线性运动 | 画面保持一张素描时人物仍可走动；播放、暂停、拖到切点两侧，双方显示同一时刻；保存重开可重放 |
| 二 | 命名时刻、临时声轨、机位视图、描述型素描与可选简彩；加入基础运镜与深度预演 | 两机位重看同一动作，修改站位后均能定位受影响帧；推轨变焦时主体大小稳定，背景透视可见变化 |
| 三 | 局部草图动画、全场定案、风格帧对照与正式生成回填。按镜接入视频服务后，以隔离样本做真实验收 | 草图与风格帧按同一切点播放；输出适配正确；生成结果换入原时间轨后，可定位并复查具体偏差 |

贯穿样片采用“敲窗—等待—降窗—首次看清头盔”。导演把首次显露延后半秒，应能立即在调度板看到玻璃的位置，在预览看到头盔仍被遮挡。绑定同一标记的声音和反应切点跟随移动，自由定位项保留原时间；若与已经锁定的镜头时长冲突，列出待处理项。修改停顿优先重排时间，修改机位标记受影响草图和风格帧，修改材质只复核相关外观及下游视频。定案后的改动列出影响范围，局部重做并重新确认。
