# 制作稿交互设计 · 正文对照编排（已撤销的设计）

当前流程见[分镜导演台](STORYBOARD_DIRECTOR.md)。以下内容存作设计记录。

[查看四栏原型](PRODUCTION_DRAFT_WIREFRAME.html)。本页为目标设计。

## 四栏共用一个场

从左至右依次为场列表、制作详情、正文表、元素编排。选场时四栏一起定位。点正文时，详情列出相关元素；点元素时，详情显示内容、正文依据、出现范围、制作要求与资产需求。窄屏可收起前两栏，优先保留正文和编排的对照。

正文表与元素编排共享纵向滚动和行边界。每个正文块占一个区段，行高取正文排版与区内元素所需空间的较大值。展开或折叠区段两侧同步。高度表示阅读与编排空间，秒数另行估定。

## 编排

右栏的每次元素出现显示为一条纵向色带。上下表示先后，左右并排可表达同时进行。一个区段可以容纳多条带，同一带可以从某块中部延伸到另一块中部。程序分配横向位置以避让重叠元素，必要时可按人物或声画类型分组。排版导致的左右位置和像素距离只用于显示。

选取正文词句后可添加元素、继续选取其他块或关联已有元素。同一片段可供多个元素引用。分别记录正文依据与编排范围，例如低鸣的依据是一句声音描写，持续范围却可以延伸到下一段对白。范围端点用正文块和区内有序位置表示，明确同步时引用同一标记。未定的终点显示开放尾端。

拖动整条带移动本次出现，拖动端点调整范围。同步项移动前显示受影响的元素。属性面板提供等价的起止位置选择器。屏蔽保留原位置并可恢复。跨区元素选中后整条高亮，可分别跳转到起点、终点与正文依据。

## 格式化制作稿

按场与正文顺序排版，保留场头、动作和完整对白。每个区段下列出本区新起的元素、声画关系和制作要求。并行项标出“同时”，跨区项在首次出现时写全，中间仅标持续，在结束处标结束。默认略去已屏蔽的出现。编排位置决定元素在哪一段呈现，正文依据用于追溯。预览与编辑使用同一批对象。

## 资产

制作详情展示“可复用资源”，区分继承资源与本元素用法。可以关联资源库中的角色定妆、场景空间基准、道具形态、通用动作或基础音色，也可先登记待补资源。例：取石和嵌石都引用能量石道具卡，分别指定失效、可用形态。详尽版制作稿展示资源及本次用法。

分镜详情分别展示“相关制作资源”和“本镜文件需求”。在后者添加首尾关键帧、场景调度图、动作参考片段等，说明构图、走位、动作或同步要求，可关联多个制作元素与共享资源，再选择或生成文件。选择已有参考文件与登记待生成文件需求是两个独立操作。

## 验收例

换石动作区同时包含旧石和新石的操作。嵌合闷响在动作末端进入声音区，阵心低鸣从声音区延续到对白区。正文引用、跨区高亮、同步滚动和制作稿预览均须反映这一安排。示例中低鸣延续至对白属于制作推导。
