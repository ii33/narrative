# 当前节点修正（schema 10）

节点每个 ID 只存一份当前对象。改名、类型、说明、精确证据或包含关系，通过统一对话或节点详情调用 Operations 修改同一对象；不先创建人工待审队列，不保存旧节点副本。

`preview_changes` / `apply_changes` 接受完整图对象与属性记录、`expected_revision` 和原因。程序检查引用、逐字证据、语境、包含循环、事件归属及物品持有者；合法批次原子提交。可以在同一批补齐场景与持有者，不能靠伪造“未知”绕过缺失。

复核发现已有重复事件时，先核对原文，再使用 `preview_event_merge` / `merge_events` 指定被合并与保留事件。合并保留证据、子项和外部关系，物理重写有类型的引用并删除重复节点，不保留重定向链。相同名称不足以证明同一事件。

属性状态变化关闭旧取值区间并追加新值；录入错误直接更正或删除错误值。按原文时间点回退会删除该点之后的事实并清理引用，不恢复节点旧名称或旧编辑版本。旧工程直接拒绝打开，不提供转换或兼容入口。

接口与边界见 [数据模型](DATA_MODEL.md) 和 [Agent API](AGENT_API.md)。
